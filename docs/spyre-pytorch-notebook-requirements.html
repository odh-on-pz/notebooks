Running UC1 RAG on Red Hat OpenShift AI Tech Preview

Using the OGX (Open GenAI Stack) APIs — RHOAI 3.5  ·  examples/ogx/uc1_rag.py

Prerequisites (cluster-side, done once by admin)

1 Install RHOAI 3.5 with OGX Operator

Enable the OGX Operator via OperatorHub in your OpenShift cluster.

2 Deploy Milvus (vector store backend)

Deploy Milvus via OperatorHub or Helm, then set the endpoint in the OGXServer CR:

MILVUS_ENDPOINT=http://milvus-service.my-project.svc.cluster.local:19530

3 Deploy a vLLM InferenceService (e.g. Mistral)

VLLM_URL=http://mistral-predictor.my-project.svc.cluster.local:80/v1
IBM Power (ppc64le): Remove --quantization fp8 from the vLLM InferenceService args. fp8 requires GPU hardware and will fail on CPU. Use no quantization flag or --quantization int8.

4 Deploy the OGXServer CR

apiVersion: ogx.rhoai.redhat.com/v1alpha1
kind: OGXServer
metadata:
  name: ogx
spec:
  env:
    - name: MILVUS_ENDPOINT
      value: "http://milvus-service.my-project.svc.cluster.local:19530"
    - name: VLLM_URL
      value: "http://mistral-predictor.my-project.svc.cluster.local:80/v1"

Step 4 — Run the RAG use case

import os
from examples.ogx.uc1_rag import ingest_documents, rag_query, summarise_document, find_similar

# OGX_BASE_URL / OGX_API_KEY already set via Data Connection env vars
print(os.environ["OGX_BASE_URL"])

# 1. Ingest documents (upload + chunk + embed + index into Milvus)
vs_id, llm_id = ingest_documents(
    file_paths=["docs/architecture.pdf", "docs/api-reference.html"],
    vector_store_name="internal_docs",
    provider_id="milvus-remote",   # use "milvus-inline" if no separate Milvus pod
)

# 2. Query
rag_query("What is the deployment architecture?", vs_id, llm_id)

# 3. Summarise a specific document
summarise_document("architecture.pdf", vs_id, llm_id)

# 4. Find similar content
find_similar("microservices communication patterns", vs_id, llm_id)

Step 5 — Optional: multi-turn follow-up

from examples.ogx.conversations import OGXConversation

with OGXConversation(model_id=llm_id, vector_store_id=vs_id, topic="arch-qa") as conv:
    conv.ask("What is the system architecture?")
    conv.ask("How does authentication work?")      # context from turn 1 included automatically
    conv.ask("Summarise what we discussed.")
    conv.print_history()

What happens under the hood

ingest_documents()
  ├── upload_document()       →  POST /v1/files
  ├── create_vector_store()   →  POST /v1/vector_stores   (Milvus-backed)
  └── index_file()            →  POST /v1/vector_stores/{id}/files
                                   OGX: Docling parse → chunk → embed → upsert to Milvus

rag_query()                   →  POST /v1/responses  (file_search tool)
                                   OGX: embed question → ANN search Milvus → inject chunks → LLM generate
